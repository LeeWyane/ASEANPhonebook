# ASEAN Phonebook

## Project Description

ASEAN Phonebook is a C# console application that allows users to store, edit, and search student contact information from five selected ASEAN countries.

This project demonstrates Object-Oriented Programming (OOP) and the use of Git for version control.

## Features

- Store student information.
- Edit an existing student's information using their student number.
- Search for students from one or multiple ASEAN countries.
- Search all students using the ALL option.
- Display search results alphabetically by surname.
- Validate country codes.

## Supported Countries

| Country | Country Code |
|---|---:|
| Malaysia | 60 |
| Indonesia | 62 |
| Philippines | 63 |
| Singapore | 65 |
| Thailand | 66 |

## Technologies Used

- C#
- .NET
- Object-Oriented Programming (OOP)
- Git and GitHub
- Visual Studio Code

## How to Run

1. Install the .NET SDK.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code or a terminal.
4. Open the terminal in the project directory.
5. Run the following command:

```bash
dotnet run
```

6. Follow the instructions displayed in the console.

## Data Storage

Student information is stored in memory while the program is running. Data is lost when the application exits, as required by the project instructions.
